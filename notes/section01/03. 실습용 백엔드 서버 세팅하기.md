# Section 1 - 3. 실습용 백엔드 서버 세팅하기

## 1. 실습용 백엔드 서버를 사용하는 이유

Next.js 기능을 **실제 서비스와 비슷한 환경에서 연습하기 위해 별도의 백엔드 서버를 사용한다.**

```text
Next.js 프론트엔드
↓
API 요청
↓
실습용 백엔드 서버
↓
데이터베이스
```

이렇게 구성하면 단순한 정적 데이터가 아니라 실제 API와 데이터베이스를 사용하는 흐름을 연습할 수 있다.

---

## 2. 백엔드 서버 준비

실습용 서버는 다음 저장소를 사용한다.

`winterlood/onebite-books-server`

저장소를 다운로드해 로컬에 준비한다.

```text
GitHub 저장소 다운로드
↓
백엔드 프로젝트 준비
```

---

## 3. Supabase 준비

데이터베이스는 **Supabase**를 사용한다.

진행 순서:

```text
Supabase 가입
↓
프로젝트 생성
↓
데이터베이스 준비
↓
백엔드 서버와 연결
```

Supabase는 이번 실습에서 백엔드 서버가 사용할 데이터를 저장하는 역할을 한다.

---

## 4. 전체 구조

```text
Next.js
↓ API 요청

실습용 백엔드 서버
↓ 데이터 조회·저장

Supabase
↓
데이터베이스
```

---

## 5. 핵심 정리

* 실제와 비슷한 환경에서 실습하기 위해 별도의 백엔드 서버를 사용한다.
* 실습용 서버는 `onebite-books-server` 저장소를 이용한다.
* 데이터베이스는 Supabase를 사용한다.
* 전체 구조는 **`Next.js → 백엔드 API → Supabase`**로 이해하면 된다.
