# Section 1 - 4. 본격적인 학습에 앞서

## 1. Next.js의 두 가지 라우터

Next.js에서는 크게 두 가지 라우팅 방식을 학습하게 된다.

```text
페이지 라우터
→ 기존 방식

앱 라우터
→ 새로운 방식
```

---

## 2. 페이지 라우터

페이지 라우터는 Next.js 초창기부터 제공되어 온 기존 라우팅 방식이다.

```text
Page Router
→ 오래전부터 사용된 방식
→ 기존 Next.js 프로젝트에서 많이 사용
```

먼저 페이지 라우터를 통해 Next.js의 기본적인 동작과 구조를 학습한다.

---

## 3. 앱 라우터

앱 라우터는 Next.js 13에서 처음 공개된 새로운 라우팅 방식이다.

```text
App Router
→ Next.js 13에서 공개
→ 새로운 구조와 기능 제공
```

기존 페이지 라우터와 구조와 사용 방식이 다르기 때문에 별도로 학습한다.

---

## 4. 학습 순서

이번 과정에서는 다음 순서로 진행한다.

```text
페이지 라우터
↓
Next.js 기본 개념 이해
↓
앱 라우터
↓
새로운 방식 학습
```

즉, **페이지 라우터를 먼저 이해한 뒤 앱 라우터로 넘어간다.**

---

## 5. 핵심 정리

* 페이지 라우터는 Next.js의 기존 라우팅 방식이다.
* 앱 라우터는 Next.js 13에서 공개된 새로운 라우팅 방식이다.
* 두 방식은 구조와 사용 방법이 다르다.
* 학습은 **`페이지 라우터 → 앱 라우터`** 순서로 진행한다.
