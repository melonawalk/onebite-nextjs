# Section 1 - 1. Next.js를 소개합니다

## 1. Next.js란?

Next.js는 **React 기반 웹 프레임워크**이다.

React만 사용할 때 별도로 구성해야 하는 기능과 개발 규칙을 함께 제공한다.

```text
React
↓
웹 애플리케이션 기능과 규칙 추가
↓
Next.js
```

즉, React를 기반으로 실제 웹 애플리케이션을 더 편리하게 개발할 수 있도록 도와준다.

Next.js는 Vercel에서 개발한다.

---

## 2. React와 Next.js의 차이

### a. React

React는 **UI를 만들기 위한 라이브러리**이다.

```text
React

→ UI 개발 중심
→ 필요한 기능을 직접 선택
→ 프로젝트 구성이 비교적 자유로움
```

### b. Next.js

Next.js는 React를 기반으로 **프로젝트 구조와 개발 규칙까지 제공하는 프레임워크**이다.

```text
Next.js

→ React 기반
→ 정해진 구조와 규칙 제공
→ 웹 개발에 필요한 기능을 함께 제공
```

따라서 개발자가 프로젝트 구조와 필요한 기능을 처음부터 모두 직접 구성해야 하는 부담을 줄일 수 있다.

---

## 3. 핵심 정리

* React는 UI 개발을 위한 라이브러리이다.
* Next.js는 React 기반의 웹 프레임워크이다.
* React는 필요한 기능을 개발자가 직접 조합한다.
* Next.js는 프로젝트 구조, 개발 규칙, 여러 웹 기능을 함께 제공한다.
* Next.js는 React를 대체하는 것이 아니라 **React를 기반으로 기능을 확장한 프레임워크**이다.
* 핵심은 **`Next.js = React + 웹 애플리케이션 개발 기능 + 개발 규칙`**이다.
